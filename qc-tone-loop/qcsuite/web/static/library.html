プリセット管理

一覧・検索・重複の確認は、本体のフォルダ一覧だけを使うので本体の音は変わりません。 中身(チェーンとノブ)はバックアップから表示します。コピーは計画を確認してから実行します(既定のコピー先は sandbox)。

一覧と検索

「表示」を押してください。
0 件を選択 コピー先

コピーのたびに元のプリセットが本体に読み込まれ、音が切り替わります。タグは引き継がれません。 同じ名前があると、本体が名前を 20 文字に切り詰めて _N を付けることがあります。

中身(チェーンとノブ)

一覧の名前を押すと、バックアップから表示します。

重複

お気に入り(ハート)と Favorite フォルダの比較

本体のお気に入り機能と、ユーザーが作った「Favorite」フォルダは別物です。名前で照合して並べます。 qcsuite はハートを付け外ししません(読むだけ)。

キャプチャー・IR・ブロックを探す

パソコンから読み込んだキャプチャーや IR は音に反映されません。選んだものを 「本体で読み込む候補リスト」として保存し、本体の画面で読み込んでください。
