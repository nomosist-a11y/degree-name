言葉で操作

言葉をグリッドの操作に置き換えるだけで、音の良し悪しは判断しません。変更は保存されず、本体でプリセットを呼び出し直すと元に戻ります。 キャプチャーと未所有プラグインのつまみ、マイクなどの文字列パラメーターは、パソコンから書いても音に反映されません(赤枠)。

指示

    パッチ JSON
    
  
    

  
    
    
    A/B 切り替え
    
    
    2 つの状態を記録して、1 クリックで行き来します。弾きながら耳で比べてください。保存はしません。

    履歴
    
    
    
    
    取り消しで戻るのは、ブロックの構成・入出力・数値のつまみ・スイッチ・バイパスです。文字列パラメーターは戻しません。
    
    
    
  
    

  
    
    
    sandbox に保存
    
    
    いまのグリッドを sandbox の空きスロットに保存する計画を作ります。内容を確認してから実行します。
