# エディターと Cortex Control の機能の比較(2026-11-11)

qcsuite のエディターを、パソコン用の純正エディター(Cortex Control)の操作にどこまで近づけたかの表です。

- 「Cortex Control」欄は、Neural DSP の公開マニュアル(Quad Cortex / Cortex Control)の内容、以前に撮った実画面のスクリーンショット、一般に知られている操作をもとにしています。実機の Cortex Control で一つずつ確かめたわけではありません(「要確認」と書いたものは特に)。
- 「ライブラリ」欄は pyquadcortex 0.40.0 の `client.py` の docstring にある、確認済みの書き込みです。
- 「qcsuite」欄の「◎」は今回(2026-11-11)入れたもの、「○」は前からあったもの、「表示」は表示だけ、「×」はできないものです。
- 確かめたのはモック(偽の本体)とテスト(pytest、JS)だけです。実機での確認は、プレイヤーの合図のあとで行います(`docs/editor-hardware-test.md` に手順を追記)。

## グリッド

| 機能 | Cortex Control | ライブラリ | qcsuite | メモ |
|---|---|---|---|---|
| ブロックを同じ行の空きマスへドラッグで移動 | あり | `move_block`(確認済み) | ◎ | ブロックのつまみ・バイパス・キャプチャーはそのまま |
| 別の行へドラッグで移動 | あり(並列の経路になる) | `move_block`。本体が分岐を自動で作る(確認済み) | ◎ | 移動のあと、本体が作った分岐を読み戻して表示 |
| ブロックの上に落とす | 入れ替え(要確認) | 直接の命令なし | ◎(入れ替え) | 空きマスを経由して 3 回の移動で入れ替え。グリッドに空きが無いときはできない |
| Option(Alt)を押しながらドラッグで複製 | あり(要確認) | 置く+値を書く | ◎ | キャプチャーは複製しない(パソコンから選んだキャプチャーは鳴らないため) |
| グリッドの外へドラッグで削除 | あり | `remove_block`(確認済み) | ◎ | |
| ホバーで出る × で削除 | あり | 同上 | ◎ | 確認なし(取り消しで戻せる)。キャプチャー・IR だけは確認する(取り消しても選択が戻らないため) |
| Delete / Backspace キーで削除 | あり | 同上 | ◎ | |
| コピー・ペースト(⌘C / ⌘V) | あり(要確認) | 置く+値を書く | ◎ | コピーはブラウザに保存(別のプリセットに貼れる)。文字列パラメーターと、選択肢の名前が分からないスイッチは貼らない |
| ブロックの ⋮ メニュー / 右クリック | あり | — | ◎ | コピー、ペースト、複製、初期値に戻す、バイパス、削除 |
| パラメーターを初期値に戻す | あり(要確認) | 同じモデルを置き直す | ◎ | キャプチャー・IR は不可。実機で「置き直すと初期値になる」かは要確認 |
| 一覧からグリッドへドラッグして置く | あり | `set_block`(確認済み) | ◎ | 前からのダブルクリックも使える |
| 一覧でダブルクリックして差し替え | あり | 同上 | ○ | |
| 矢印キーで選択を動かす(上下で行を移る) | あり | — | ○ | |
| 取り消し・やり直し | なし(本体にもない) | — | ○ | 上の操作はすべて 1 回で取り消しの 1 単位。移動の取り消しは「移動で戻す」ので、キャプチャーも失われない |
| A/B 比較 | なし | — | ○ | |

## 行のつなぎ方

| 機能 | Cortex Control | ライブラリ | qcsuite | メモ |

| 行の出力(Out 1/2、Out 3/4、Send、USB、Multi Out、次の行へ) | あり | `set_chain_output`(確認済み) | ◎ | 同上。`MULTIPLE` を Multi Out と表示 |
| 「Prev. row」の表示 | あり | — | ○ | |
| 分岐(スプリット)を作る・位置を変える・外す | あり | `set_split` / `clear_split`(確認済み)。行 1 と行 3 だけ | ◎ | 出力ポートのメニューから。分岐の位置はグリッドに青い線で表示。取り消しできる(スナップショットに分岐の位置を追加) |

## プリセット(DIRECTORY)

| 機能 | Cortex Control | ライブラリ | qcsuite | メモ |
|---|---|---|---|---|
| セットリストとプリセットの一覧 | あり | `list_folders` / `list_presets` | ◎ | 「DIRECTORY」タブかプリセット名のクリックで一覧。セットリストの一覧は 60 秒使い回す(取り直すと 20 秒かかり、本体のロックを持つため)。詳しい管理はプリセット管理の画面 |
| プリセットの呼び出し | あり | `recall_preset` | ◎ | エディターのプリセット名・DIRECTORY タブから一覧で選ぶ。保存していない編集があるときだけ確認する(純正と同じ)。呼び出すと取り消しの履歴はそこで区切る |
| 名前を付けて保存 | あり | `save_current_preset` | ○(sandbox だけ) | エディターの保存アイコン。計画を見てから実行。プレイヤーのフォルダには書かない |
| 上書き保存 | あり | 同上 | × | 安全ルールで、使用中のスロットは上書きしない |
| プリセット名の変更・移動・コピー・削除 | あり | `move_preset` / `copy_preset` / `delete_preset` | 一部(プリセット管理、sandbox の計画) | エディターからは行わない(安全ルール) |
| エディター内の < > で前後のプリセットへ | あり | `recall_preset` | ◎ | 同じセットリストの前後の(空きでない)スロットへ。端では反対側へ回る。いま読み込まれているスロットは本体の通知(SetlistPosition)か、エディターからの呼び出しで知る |

## 本体側の変更の反映

| 機能 | Cortex Control | ライブラリ | qcsuite | メモ |
|---|---|---|---|---|
| 本体の画面・フットスイッチで変えたつまみ・バイパス・ブロック | 画面がすぐ追従 | 本体は接続時に購読した種類(Grid、Scene、RecallPreset、PresetDirty、SetlistPosition など)を送ってくる(`_SUBSCRIBE_TYPES`) | ◎ | 届いた通知を数えるだけ(本体への問い合わせなし)。数が変わったら、グリッドを 1 回読み直す。つまみやブロックのドラッグ中、書き込み中、ダイアログを開いている間は読み直さない |
| 本体でのシーンの切り替え | 追従 | 同上(Scene) | ◎ | 同上 |
| 本体でのプリセットの切り替え | 追従 | 同上(RecallPreset、SetlistPosition) | ◎ | 同上。取り消しの履歴は、グリッドの配置が履歴と違えば使えないようにした(別のプリセットに古い変更を書かないため) |
| 通知を受け取れないとき | — | 受け取りは pyquadcortex の内部の仕組みを使う | ◎(代わりに 5 秒ごとに読み直す) | 重いフォルダ一覧は定期的には読まない |
| 食い違ったとき | 本体が正 | — | ◎ | 画面を本体に合わせる。エディターから書いて合わせることはしない。古い画面のまま書こうとした操作は、何も書かずに読み直す(既存) |

## 本体の事実で、気をつけていること

- キャプチャーを置いた直後のバイパスは、本体に捨てられることがある(読み戻して送り直す。既存の処理)。
- パソコンから保存すると、バイパスしたキャプチャーはオンで保存される(保存の計画で注意を出す。既存)。
- スイッチは選択肢の名前で書く。名前が無いスイッチは、貼り付けでも書かない。
- キャプチャー・IR・未所有プラグインは、パソコンから書いても音が変わらない。だから、キャプチャーのコピー・複製・初期値に戻すは行わない。移動はできる(本体の中で動くだけなので、キャプチャーはそのまま)。
- 行をまたぐ移動では、本体が分岐を自分で作る。取り消すときは、移動で戻したあと、元の分岐の状態を書き直す。
