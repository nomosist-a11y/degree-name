# エディターと Cortex Control の機能の比較(2026-11-11)

qcsuite のエディターを、パソコン用の純正エディター(Cortex Control)の操作にどこまで近づけたかの表です。

- 「Cortex Control」欄は、Neural DSP の公開マニュアル、以前に撮った実画面のスクリーンショット、一般に知られている操作をもとにしています。実機の Cortex Control で一つずつ確かめたわけではありません(「要確認」と書いたものは特に)。
- 2026-11-11(第 3 回)に、マニュアルの目次を上から順に見て、表に無かった機能を足しました。使ったのは次の節です(名前だけを挙げます。本文は写していません)。
  - Quad Cortex User Manual 4.1.1(<https://neuraldsp.com/manual/quad-cortex>):「03 Quick Start Guide」(Master Volume、Tuner、Tempo & Metronome、Modes、Gig View、I/O Settings)、「04 The Grid」(Virtual Devices、Blocks、Parameter Editors、Virtual Device Presets、Expression Pedals、Looper X、CPU Monitor)、「05 The Directory」(Favorites & Recent、Presets、Preset Deletion、Neural Captures、Impulse Responses、Plugin Presets、Bulk Actions、Sorting Items、Searching Items、Setlists & Folders、Uploading Items to Cortex Cloud)、「06 Neural Capture」、「07 Plugin Compatibility」、「08 MIDI Support」(MIDI Settings Menu、Preset MIDI Out、Incoming MIDI Messages)、「10 Device Settings Menu」、「11 Cortex Control App」(User Interface、Multiple Plugged Devices、Neural Capture Version 2、User Content Transfer、Local Backups、CorOS Updates via USB、Keyboard Shortcuts)。
  - Neural DSP のサポートにある Cortex Control User Manual(2026-01-21 版。<https://support.neuraldsp.com/help/neural-dsp-user-manuals> から)。今回は目次の確認までで、本文は読めていません(取得の上限に達したため)。Cortex Control 独自の細かい操作は「要確認」のままです。
- 「ライブラリ」欄は pyquadcortex 0.40.0 の `client.py` の docstring にある、確認済みの書き込みです。
- 「qcsuite」欄の記号:
  - 「◎」は 2026-11-11 に入れたもの。「◎ 2026-11-11 第 3 回」は同じ日の 3 回目(この版)で入れたもの、または入れている途中のもの(ほかの担当が同時に作業中。実際に入ったかは、まとめる人が確かめる)。
  - 「○」は前からあったもの。「表示」は見るだけ(書き込まない)。
  - 「×」は入れないと決めたもの(安全ルール、本体の仕様、ライブラリに命令が無い)。
  - 「未」はまだ入れていないもの(入れてもよいが、手が回っていない)。
- 確かめたのはモック(偽の本体)とテスト(pytest、JS)だけです。実機での確認は、プレイヤーの合図のあとで行います(`docs/editor-hardware-test.md` に手順を追記)。

## 本体の事実で、気をつけていること

- キャプチャーを置いた直後のバイパスは、本体に捨てられることがある(読み戻して送り直す。既存の処理)。
- パソコンから保存すると、バイパスしたキャプチャーはオンで保存される(保存・名前の変更の計画で注意を出す)。
- スイッチは選択肢の名前で書く。名前が無いスイッチは、貼り付けでも書かない。
- キャプチャー・IR・未所有プラグインは、パソコンから書いても音が変わらない。だから、キャプチャーのコピー・複製・初期値に戻すは行わない。移動はできる(本体の中で動くだけなので、キャプチャーはそのまま)。
- 行をまたぐ移動では、本体が分岐を自分で作る。取り消すときは、移動で戻したあと、元の分岐の状態を書き直す。
- 本体はプリセットを名前(`<セットリスト>/<名前>.pb`)で消したり動かしたりする。だから同じ名前が 2 つあるセットリストでは、名前の変更・移動・削除の計画を作らない。

## どれだけ入れたか

数えたのは、上の表で「Cortex Control」欄が「あり」の行だけです(「なし」の行と、qcsuite だけの機能、「—」の行は数えていません)。1 行を 1 機能として数えています。

| 区分 | 数 | 割合 |
|---|---|---|
| Cortex Control の機能(表の行) | 84 | 100% |
| 入れた(◎・○。sandbox だけ・一部を含む) | 49 | 58% |
| 　うち 2026-11-11 第 3 回 | 14 | 17% |
| 表示だけ | 5 | 6% |
| 入れないと決めた(安全ルール・本体の仕様・ライブラリに命令なし) | 21 | 25% |
